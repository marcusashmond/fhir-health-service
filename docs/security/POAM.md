# Plan of Action and Milestones: FHIR Health Service

This is a sample POA&M for a personal project. The FHIR Health Service has not been formally authorized, and no authorizing official has reviewed these items.

* Companion document: [System Security Plan](SSP.md)
* Date opened: November 7, 2026
* Point of contact: Marcus Ashmond, system owner and ISSO
* Source of findings: Self assessment against the NIST SP 800-53 Revision 5 Moderate baseline, done while writing the SSP

Every control the SSP marks Partially Implemented or Planned appears in at least one item below. Risk is rated High, Moderate, or Low based on the likelihood and impact to PHI. All items are open.

## Remediated Before This POA&M Was Opened

These weaknesses were found during the assessment and fixed before the items above were recorded. Each change is a separate commit in the repository.

* HTTP server had no timeouts or body size limit (SC-5, SC-10). Added `ReadTimeout`, `WriteTimeout`, `IdleTimeout`, and a 1 MiB limit through `http.MaxBytesHandler` in `main.go`.
* Reads of the audit trail were not audited, and audit records had no source address (AU-2, AU-3). Wrapped `/audit-logs` with the audit middleware and added a `source_ip` column through migration `0004_add_source_ip_to_audit_logs.sql`.
* The anomaly alert logged the patient reference and the measured value to stdout (SI-11). The alert now logs only the observation ID and LOINC code.
* CI had no vulnerability scanning (RA-5, SI-2). Added `govulncheck`. Its first run found 14 reachable vulnerabilities, fixed by moving to Go 1.26.10 and updating `klauspost/compress` and `golang.org/x/text`.
* The pod ran without a security context and with no network restrictions (AC-6, SC-7). Added `runAsNonRoot`, a read only root filesystem, dropped capabilities, disabled privilege escalation, the `RuntimeDefault` seccomp profile, and a NetworkPolicy.
* The audit middleware had no tests (SA-11). Added tests for record content, source IP, `X-Forwarded-For` handling, insert failure, the full queue path, and shutdown draining.
